# Orientações para agentes

## Objetivo

O projeto `clone-tabnews-ia` tem como objetivo desenvolver um clone do TabNews com auxílio de agentes de IA.

## Comunicação e implementação

- Comunicar-se com o usuário e escrever a documentação em português.
- Priorizar soluções simples, com o mínimo de código necessário e seguindo as convenções modernas do Next.js.
- Evitar dependências, abstrações e configurações que não sejam necessárias à tarefa.
- Preservar a acessibilidade ao alterar a interface.

## Organização do projeto

- Manter a aplicação na raiz do projeto.
- Utilizar apenas o repositório Git da raiz. Não criar repositórios aninhados nem submódulos para o site.
- Consultar o `README.md` e o `package.json` para obter os comandos, as dependências e os requisitos de execução vigentes.
- Respeitar o lockfile e não versionar dependências instaladas ou artefatos de build.
- Conferir o estado local e remoto antes de enviar alterações e respeitar o escopo solicitado pelo usuário.

## Manutenção deste documento

Manter aqui apenas contexto e orientações duradouras, úteis em diferentes sessões e para qualquer agente. Não registrar estado atual das funcionalidades, versões de dependências, resultados de verificações, histórico de commits, caminhos temporários ou particularidades de uma sessão. Consultar o código, as configurações e o histórico Git para essas informações.
